# KeepMeHonest legal-es / M2 — source retrieval and independent use

**Experimental, not validated for client matters or production.** Maintains Core 0.1.1 unchanged.

## Security / permitted traffic

- User-provided argument stays local, and no model service receives it.
- Offline by default. `--allow-official-network` allows **only** explicit BOE IDs or TC ECLI + numeric HJ document ID. Never use case facts or client identifiers in queries.
- Read-only GET; exact HTTPS host and endpoint allowlist, redirects blocked, response size bounded, timeouts, MIME checks, XML DTD/entity rejection. No CENDOJ request code.
- Do not enter real confidential cases until a dedicated privacy/security audit is accepted; even local output may contain sensitive text.
- BOE XML endpoint: /datosabiertos/api/legislacion-consolidada/id/{BOE-ID}/texto/indice and /texto/bloque/{block-id}.
- TC HJ: /HJ/Resolucion/Api/json/{HJ-ID} (linked from the public resolution). Structured `RESOLUCIONES_FUNDAMENTOS` and `RESOLUCIONES_DICTAMEN` provide numbered sections. Identity requires exact HJ ID, `SENTENCIA`, year and sentence number matching the numeric TC ECLI; other resolution types are intentionally unsupported in M2. The human-readable locator is `/HJ/es/Resolucion/Show/{HJ-ID}`. A bare ECLI cannot be converted reliably into an HJ ID without an authorized search contract.

## CLI (fork root)

```bash
PYTHONPATH=src python3 -m keepmehonest_legal_es --text-file examples/legal_es/argument_m2.txt
PYTHONPATH=src python3 -m keepmehonest_legal_es --text-file examples/legal_es/argument_m2.txt \
  --boe BOE-A-1978-31229,24,2024-01-15 --allow-official-network --output review.json
PYTHONPATH=src python3 -m keepmehonest_legal_es --text-file examples/legal_es/argument_m2.txt \
  --tc ECLI:ES:TC:2024:1,30062,FJ1 --allow-official-network --output review.json
```

Exit status: `0` = report created and requested retrievals succeeded (if any); `2` = invalid input; `3` = report created but one or more requested source fetches were unavailable. Inspect `coverage.source_attempts` even for exit `0`.

ECLI/HJ pairing example is based on official HJ decision 30062, but successful parsing on the current site must be established by a live smoke test on the developer Mac. No unrestricted jurisprudence search exists in M2.

Local evidence (from user): pass `--evidence-json evidence.json`, array with fields conforming to `LegalEvidence`: source (BOE, TC, ORDINARY_COURTS), identifier, section_id, text, official_url, title, decision_date / version_date. **Origin is forcibly USER_SUPPLIED** and never regarded as authenticated.

## Interpretation of report

- `lexical_verdict` is *only* a Core heuristic, not legal support.
- `review_status` always `HUMAN_REVIEW_REQUIRED`. `legal_support`, `argument_quality` remain `NOT_ASSESSED`.
- A BOE `version_date` is a version's `fecha_vigencia` metadata, not a conclusion of legal applicability. A historical selection fails closed when dates are missing or contradictory. BOE consolidated text is informational; official publication must be checked.
- A TC document/section requires matching official JSON identity fields (ID, SENTENCIA, number, year) to the explicitly supplied TC ECLI; JSON itself does not publish a literal ECLI field. FJ and FALLO are read directly by numbered structured section without guessing HTML boundaries. Wrong or duplicated sections are not substituted; only numeric SENTENCIA references are supported.
- `SOURCES_REQUIRED` / `UNAVAILABLE` / `NOT_ENOUGH_EVIDENCE` never means a legal claim is false.
- CENDOJ and general case-law search remain disabled; this is **targeted retrieval**, not corpus discovery.
- Reports track source attempts, raw transport hashes and section hashes; live output is not byte-for-byte reproducible over time without capturing the original source response. Treat reports as provisional until the source snapshots are archived under an approved policy.

## Acceptance gates / missing work

1. Run unit tests and whole-core regression tests on a cloned fork; record output.
2. Run BOE live read-only smoke test on an innocuous public article; compare version/date and text with official website.
3. Run TC live read-only smoke for HJ 30062 / ECLI:ES:TC:2024:1 / FJ1; inspect that FJ boundaries match the source; if parsing fails, keep connector disabled.
4. Confirm access conditions, rate limits and permitted commercial reuse before any hosted or commercial deployment.
5. Privacy threat model, output redaction/custody rules, provenance snapshots, semantic/legal evaluation and cross-authority coverage remain open.

# KeepMeHonest Spanish Legal Edition — M7-A: Documentary Review Gate

**Status:** technical candidate; requires full local validation. **Base:** published fork `Nicolas-Spoel/claims-verifier-core` at commit `6b2cf8fede26e77267843933d81433d4cd1b88dd` (M6-C2). **Scope:** two new files only: `m7_review_gate.py` and `test_m7_review_gate.py`, plus this document. Does not edit the generic Core, M2–M6, connectors, data corpus or previously published reports.

## Objective and strict interpretation

M3 already reports whether a **literal quote** is found within a specifically cited source section and emits non-semantic legal-scope review cues. M7-A turns those M3 results into an **offline, text-free human review queue**, with consistency checks, per-claim workflow categories and deterministic reason codes. It is a *documentary workflow* tool, not a legal-support, legal truth, or legal-applicability classifier.

The possible `documentary_workflow` labels are:

- `LITERAL_QUOTE_LOCATED_NOT_LEGAL_SUPPORT`: a quoted passage matches an M3 source section. This **does not** establish that the quoted passage entails the proposition, that the source is in force, or that it is applicable.
- `QUOTATION_DISCREPANCY_REQUIRES_REVIEW`: an M3 quoted passage was not found literally in the cited section. This is **not** a legal falsity label.
- `CITED_SECTION_WITHOUT_VERIFIABLE_QUOTE`: the section was identified, but no unambiguous literal quotation was verified.
- `CITATION_OR_SECTION_UNRESOLVED`: remaining unresolved documentary issues, including missing identifiers/evidence or ambiguous sections.

**Every claim is `human_review_required=true`, `legal_support=NOT_ASSESSED`, `legal_applicability=NOT_ASSESSED`, and `legal_truth_verdict=NOT_PRODUCED`.** No probability, confidence score, lawfulness determination or misleading negative inference is produced.

M7-A ignores Core lexical verdicts and scores, never treats an unmatched source as evidence of falsity, and does not inherit a citation from an adjacent clause. It preserves M3-B review cues like temporal scope, absolute statements, exceptions, and sibling-clause citations without asserting that these cues amount to errors.

## Data and security boundaries

1. **Offline only:** no network requests, no web browsers, no app installs, no CENDOJ access, no LLM, no additional models or dependencies. The CLI calls the existing `verify_argument()` (M3/Core) on locally read inputs; it does **not** fetch official sources itself.
2. The input `--text-file` is an argument supplied by a lawyer or tester. `--evidence-json` is an **optional** JSON array of `LegalEvidence` objects with section text. **All JSON-supplied evidence is forcibly labeled `USER_SUPPLIED`**, regardless of the `origin` field, to prevent provenance spoofing. To fetch official sources, use the separately gated M2 or M6 commands; M7-A itself does not incorporate their raw captures.
3. The CLI checks file size and rejects final-component input symlinks, special files and duplicate JSON keys. Inputs are local, not transmitted.
4. `--output` is mandatory; it must designate a **new, absolute file outside the Git repository** under an existing directory, created with `0600` file permissions. No overwrite. The standard output prints only aggregate counts.
5. Output omits **claim text, judicial source text, snippets, source titles, client names and full identifiers**. It contains claim and evidence SHA-256 fingerprints and review flags; **treat even these hashes as sensitive metadata** and do not publish real-case reports.
6. The M3 manifest's keys, per-claim hashes, associated evidence keys, source origin and section provenance are checked for internal consistency. **This cannot cryptographically authenticate the original downloaded source without the raw bytes** and does not establish rights of reuse. `source_authenticity_independently_verified=false`.
7. The model-free synthetic tests are regression tests only. `expert_gold_cases=0`, `legal_accuracy_measured=false`, `rights_cleared=false`; no precision/recall or accuracy claims about Spanish law.

## Minimal demonstration with synthetic data (no real legal excerpts)

To demonstrate the abstention rule, create a synthetic local text file. Its content does not quote the real Spanish Constitution; the BOE-ID in this example is used only as a fixture identifier:

```bash
printf '%s\n' 'El art. 24 BOE-A-1978-31229 dice «Esta es una frase de prueba sin valor jurídico ni aplicación real».' > /tmp/kmh-m7-synthetic-argument.txt

cat > /tmp/kmh-m7-synthetic-evidence.json <<'JSON'
[
  {
    "source": "BOE",
    "identifier": "BOE-A-1978-31229",
    "section_id": "a24",
    "text": "Esta es una frase de prueba sin valor jurídico ni aplicación real",
    "official_url": "https://www.boe.es/buscar/act.php?id=BOE-A-1978-31229#a24",
    "title": "EJEMPLO SINTÉTICO: NO ES TEXTO OFICIAL",
    "origin": "OFFICIAL_FETCH",
    "version_date": "1978-12-29"
  }
]
JSON

PYTHONPATH=src python3 -m keepmehonest_legal_es.m7_review_gate \
  --text-file /tmp/kmh-m7-synthetic-argument.txt \
  --evidence-json /tmp/kmh-m7-synthetic-evidence.json \
  --output /tmp/kmh-m7-synthetic-review.json
```

The `origin: "OFFICIAL_FETCH"` in this synthetic JSON is **intentionally untrusted** and is forcibly replaced with `USER_SUPPLIED`. The result must not present the evidence as an independently checked official fetch. The output should say `OFFLINE_DOCUMENTARY_REVIEW_QUEUE_NOT_LEGAL_VERDICT` and preserve `legal_support_assessed=false`, even if M3 locates the literal quotation. The sample stores no real protected information. Inspect `/tmp/kmh-m7-synthetic-review.json` for the text-free review queue. Remove only these explicitly named synthetic files after testing if desired; no general cleanup commands.

## Next gates, outside M7-A

M7-A is **not an autonomous Spanish-law verifier**. M7-B or later work involving legal entailment, exception reconciliation, temporal applicability or judicial doctrine needs qualified legal ground truth, tested retrieval coverage and an implementable private/cost-controlled deployment path. Until then, only documentary flags and human review queues can be claimed. M6-C2 retrieves TC **publication dates**, not jurisprudence-complete substantive search results. CENDOJ remains disabled.
